2026-10-27。针对用户对当前 Pizza pet v3 造型的反馈，先核实参考项目的实际实现。后续 v4 已按此方向替换运行时，当前效果见 [系列文档](README.md)。

调研版本：[Fei2411/DS-Bot @ de55888](https://github.com/Fei2411/DS-Bot/tree/de55888a93983fc51c94f7d22bc94b4f8293205d)。

## 实际渲染方式

内置角色采用「开发时生成立体造型 → 固定视角投影为 SVG 图层 → 浏览器运行 CSS 动画」。并不是持续运行的 WebGL 角色，也不是视频或逐帧精灵图。

- [dev/characters.mjs](https://github.com/Fei2411/DS-Bot/blob/de55888a93983fc51c94f7d22bc94b4f8293205d/ds-bot/dev/characters.mjs)：使用 SDF 球体、椭球、圆角挤出等构造体积，固定 yaw 34°、pitch 16°、roll 10°；射线采样和轮廓提取生成身体、贴花、阴面、高光路径。眼睛的位置与宽窄也按表面朝向投影。
- [src/client/characters.js](https://github.com/Fei2411/DS-Bot/blob/de55888a93983fc51c94f7d22bc94b4f8293205d/ds-bot/src/client/characters.js)：运行时只持有 SVG 路径表。侧面叠加约 14% 黑色，高光约 16% 白色。两条胶囊眼睛通过 mask 从所有身体图层挖空，露出背景；没有大眼白、黑瞳孔或额外描边。每个实例分配唯一 mask id。
- [src/client/mark.js](https://github.com/Fei2411/DS-Bot/blob/de55888a93983fc51c94f7d22bc94b4f8293205d/ds-bot/src/client/mark.js)：区分身体、整体眼睛和视线层；指针更新通过 rAF 合并后写 CSS 变量。相同 Bot 的动作类型和延迟稳定，聊天记录中的头像不持续动画。上传图片是另一条路径，只做整体动作。
- [src/client/styles.js](https://github.com/Fei2411/DS-Bot/blob/de55888a93983fc51c94f7d22bc94b4f8293205d/ds-bot/src/client/styles.js)：身体与眼睛独立动画。活泼档在 5 秒内眨眼两次，9 秒循环中只短暂跳跃、摇摆或伸展；眨眼后略微回弹。悬停有倾身、蹭动和闭眼笑，点击有短促反馈；不同工作状态对应不同动作。支持减少动态效果。

## 当前 Pizza v3 的问题

实时 3D 只解决渲染方式，不能保证角色设计质量。当前模型的食品轮廓偏直白，眼白、黑瞳孔、描边和嘴部叠加后显得幼稚；材料和视角也未形成统一的品牌图形语言。继续增加五官与随机摆动不能解决这些问题。

此前将实时 3D 作为优先选择过于笼统。对于固定视角、约 64px 的顶部 pet，DS-Bot 的分层矢量方式更容易保持轮廓、颜色和表情的一致性，也可减少持续 GPU 渲染。

## v4 造型约定

- 保留 Pizza 的原创角色身份，不直接搬用 DS-Bot 的鲸鱼、星星或其他轮廓。
- PIP 先做一个清楚、短胖、圆润且有侧面厚度的主体；减去真实食物纹理与琐碎配件。
- 回到两条有透视宽窄差的胶囊眼睛；以开合、位置和拉伸表达情绪，撤下 v3 的大眼白、瞳孔描边和常驻嘴。
- 饱和主色、明确阴面和少量高光形成体积，避免浅色奶油滤镜及大面积高光。
- 身体、眼睛、视线独立。先保证待命眨眼、目光跟随、短摇头和触摸反馈顺畅，再扩展工作状态。
- 动作以安静停留为主，短动作后回到稳定姿态；保留拖动、独立悬浮、贴顶默认位置、无小标题和对话渐隐。
- 当前 v3 录屏仅保留为过程记录，不作为通过视觉评审的最终效果。
